# 👥 User Guide - For Portfolio Visitors

## What Is This?

This portfolio includes an **AI-powered assistant** that can answer questions about Gourab Ganguly's skills, experience, and projects instantly!

## How to Use the Chatbot

### Step 1: Find the Chat Button

Look for the **floating button** in the bottom-right corner of any page:

```
                                    [💬]
                                    ^^^^
                                  Click me!
```

### Step 2: Open the Chat

Click the button to open the chat window:

```
┌─────────────────────────────────────┐
│ 🤖 AI Assistant          [Clear]    │
├─────────────────────────────────────┤
│                                     │
│ 🤖 Hi! I'm Gourab's AI assistant.  │
│    I can help you learn about his  │
│    skills, experience, and         │
│    projects. What would you like   │
│    to know?                        │
│                                     │
│ Quick questions:                   │
│ [What are your main skills?]       │
│ [Tell me about your projects]      │
│ [What's your experience?]          │
│ [How can I contact you?]           │
│                                     │
├─────────────────────────────────────┤
│ [Type your message here...] [Send] │
└─────────────────────────────────────┘
```

### Step 3: Ask Questions

**Option 1: Click a Quick Action**
Click any suggested question to auto-send it.

**Option 2: Type Your Own Question**
Type in the input box and press Enter or click Send.

### Step 4: Get Instant Answers

The AI responds in 2-4 seconds with helpful information!

## What Can I Ask?

### ✅ Good Questions

**About Skills:**
- "What technologies do you work with?"
- "Do you know .NET Core?"
- "What's your experience with React?"
- "Tell me about your database skills"

**About Projects:**
- "What projects have you built?"
- "Tell me about the Tea ERP system"
- "Show me your MERN projects"
- "What's your most recent project?"

**About Experience:**
- "Where do you work?"
- "How long have you been coding?"
- "What's your current role?"
- "Tell me about Ancile"

**About Contact:**
- "How can I reach you?"
- "What's your email?"
- "Can we work together?"
- "Are you available for hire?"

### ❌ What NOT to Ask

The AI is focused on Gourab's portfolio only. It won't answer:
- General programming questions ("How do I learn React?")
- Unrelated topics ("What's the weather?")
- Code help ("Debug my code")
- Personal advice ("Should I learn Python?")

Instead, it will politely redirect you to portfolio-related questions!

## Troubleshooting

### Chat Button Not Appearing?
- Make sure JavaScript is enabled
- Try refreshing the page
- Check if an ad blocker is interfering

### Bot Not Responding?
- Wait a moment (it takes 2-4 seconds)
- Check your internet connection
- Try refreshing the page

### Got an Error Message?
- "Too many requests" - Wait 1 minute before sending more messages
- "Something went wrong" - Try again in a moment
- Other errors - Refresh the page

### Can't Type in Input?
- Click the input box to focus
- Check if chat window is fully loaded
- Try closing and reopening the chat

## Privacy & Data

### What Gets Saved?
- Your questions and the bot's responses
- Session ID (anonymous identifier)
- Timestamp of messages

### What Doesn't Get Saved?
- Personal information (unless you provide it)
- IP address (not stored in chat history)
- Browsing behavior

### How Long Is It Saved?
- Conversations are automatically deleted after 30 days
- You can clear your chat anytime with the Clear button

### Is It Secure?
- All communication is encrypted (HTTPS)
- No sensitive information is exposed
- API keys are protected server-side
